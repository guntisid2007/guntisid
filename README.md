# Sid Gunti — Portfolio

A responsive React portfolio for Siddharth Sharma Gunti, built around his work in embedded systems, robotics, engineering research, and digital media.

## Stack

- React 19 and Vite
- Tailwind CSS 4
- Framer Motion
- Phosphor Icons

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The optimized site is written to `dist/`.
